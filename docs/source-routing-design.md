## 1. Проблема

`choose.choose()` выбирает формат **вслепую**:

```
fmt = _pick_format(cfg.weights, sad_topic)   # элемент в этот момент не смотрим
```

Единственный фильтр — `_SAD_SAFE = {news, facts, quote}` для траурных тем. Ни тип
материала, ни наличие в нём даты/цифры/спикера/видео на выбор формата не влияют.

Масштаб: «фоновые» форматы (`facts` 20, `quote` 6, `behind_scenes` 5, `review` 5,
`opinion` 5, `comparison` 4, `riddle` 4) = **49 из 110 веса ≈ 45 %** постов. Все они
требуют материала не-новостного типа, а `collect` собирает новости из 28 фидов.

Подтверждение живьём (сессия 1, 19.10, `demo_posts.py`):

* `facts` на новости про трейлер → пересказ новости вместо «малоизвестного факта»
  (spec `facts.txt` прямо запрещает пересказ);
* `quote` на новости без цитаты → `quote{}` заполнен формально, но цитаты в посте нет,
  `headline` не цитата (spec: «Для quote — сама цитата»).

**Цель:** формат выбирается только из множества допущенных для данного материала.
**Не цель:** учить модель писать лучше (это Фаза 6, промпты).

## 2. Принцип

Три слоя, все детерминированные и бесплатные (никаких LLM-вызовов):

1. **Класс материала** (`kind`) — что это за текст: новость, интервью, рецензия…
   Определяется по фиду + сигналам в `title`/`snippet`.
2. **Требования** (`signals`) — есть ли в материале дата / числа / спикер / видео.
3. **Допуск формата** — формат разрешён, если его класс ∈ определённых **и**
   его требования выполнены. Выбор формата — взвешенный рандол **внутри допущенных**
   (веса ренормализуются).

Правило безопасности: сигналы только **допускают** форматы, никогда не запрещают
сверх маппинга. Если допущено ничего не оказалось — фолбэк `news`.

### 3.1 Сигналы требований (4)

| signal | Проверка по `title + snippet` (+ поля элемента) |
|--------|--------------------------------------------------|
| `date` | день+месяц(+год), «лето/осень 2027», «в прокате с», release date, дата премьеры |

| `video` | `item.video_url` непустой **или** youtube.com/nicovideo/в заголовке «видео» |

## 5. Конфиг (правляется без кода)

### 5.1 `config/sources.yaml` — класс фида как априор

```yaml
- name: Deadline
  url: https://deadline.com/feed/
  kind: mixed        # пресса: решает классификатор элемента
- name: YT/IGN
  url: https://www.youtube.com/feeds/videos.xml?channel_id=...
  kind: video        # 12 YouTube-фидов: трейлеры/видео по умолчанию
```

Группы 28 фидов: 15 пресс → `mixed`, 2 Reddit → `mixed`, 12 YT → `video`.
Значение: `mixed` | `video` | `trailer` | `boxoffice` | `archive`.

### 5.2 `config/formats.yaml` — маппинг §4

```yaml
routing:
  enabled: true          # рубильник отката
  fallback: news
  when:         {kinds: [release_date, festival], require: [date]}
  quote:        {kinds: [interview, news],        require: [speaker]}
  facts:        {kinds: [archive, production, interview, analysis]}
  # ... остальные 16
```

### 5.3 Валидация при загрузке (`kino/config.py`)

Неизвестный формат / класс / требование → `ConfigError` на старте. Опечатка в
конфиге не должна превращаться в «бот молчит сутки» (тот же принцип, что в
`schedule.parse_windows`).

## 8. Тесты (ожидаемо ≈30 новых)

1. Детект классов: YT-фид → `video`; «Review: …» → `review`; «интервью» → `interview`;
   «как снимали» → `production`; «15 ноября» → `release_date`; чистая новость → `news`.
2. Требования: `when` не допускается без даты; `infographic` без числа; `quote` без
   спикера; `trailer` без `video_url`.
3. `allowed_formats`: пустое пересечение → `[fallback]`.
4. Веса ренормализуются внутри allowed; fixed seed, 1000 роллов — недопущенный формат
   не выпадает ни разу.
5. Sad-фильтр применяется после маршрута.
6. Конфиг: загрузка `kind`/`routing`; неизвестный ключ → `ConfigError`.
7. Drift-guard: все 16 форматов `weights` присутствуют в `routing` (как `test_format_registry`).
8. Интеграция `choose`: на элементе с `video_url` не выпадают `facts/riddle/opinion`.
9. Регресс: `routing.enabled: false` даёт прежнее распределение.

### 9.1 Лог работ

**Фаза 2 (19.10, коммиты dd92b34 / 09d4ae0 / 1e8a652, конфиг + валидация, pytest 505).**
`sources.yaml`: поле `kind` у всех 28 фидов (17 `mixed`, 11 `video`). Reddit/boxoffice
остался `mixed` — решение владельца 5. `formats.yaml`: секция `routing` (16 правил,
`enabled: true`, `fallback: news`) и смена весов `facts` 20→8, `news` 15→21,
`when` 10→16 (сумма 110). `config.py`: валидация на старте — неизвестный `kind`
источника, неизвестный класс/требование в правиле и формат из `weights` без
правила дают `ConfigError`; при отсутствии секции `routing` берётся
`DEFAULT_ROUTING` из `kino/routing.py`.

Три вещи, поймавшиеся при реализации:

1. **Секция `routing` опциональна, но неполная — ошибка.** Если секции нет вовсе,
   подставляется канон из кода (загрузка не падает). Если секция есть, а правила
   для формата нет — это тихий мёртвый формат, поэтому `ConfigError`. Разница
   важна: случайно удалённая строка должна быть громкой.
2. **Проверка типа до `dict()`.** `routing: ["не", "словарь"]` давал `ValueError`
   из недр `dict()` вместо понятного `ConfigError`. Проверка типа вынесена вперёд.
3. **YAML нельзя пересериализовать.** Первый проход записал конфиги через
   `yaml.dump` и уничтожил комментарии (9 и 4 штуки) — в них причины, почему
   Reddit урезан и почему YT-фиды живые только с сервера. Файлы восстановлены из
   HEAD, правки наложены точечно: диффы 33 и 105 строк вместо 149 и 340.

Тесты: `tests/test_config_routing.py` (12) — валидация, фолбэк на `DEFAULT_ROUTING`,
дрейф-гард «секция в конфиге == канон в коде»; `tests/test_config.py` (+10) —
`kind` у источников, покрытие `weights` правилами, веса 8/21/16.

**Фаза 1 (19.10, `kino/routing.py` + `tests/test_routing.py`, 51 тест, pytest 482).**
Модуль изолирован — в бою ничего не изменилось. Два решения, принятых по ходу
реализации (отклонений от §3–§4 нет, это уточнения механики):

1. **Префиксные маркеры `*`.** Точные фразы с границей слова не ловили
   «reviews», «номинации», «премьеры» — морфология съедала половину срабатываний.
   Маркер вида `"номинац*"` матчит любую форму слова; без `*` правая граница
   обязательна («preview» не считается за «review»).
2. **Сигнал `speaker` ужесточён.** Прямая речь в кавычках (заголовок или сниппет)
   ИЛИ глагол речи **в заголовке**. Глаголы издателя (confirmed / revealed /
   reportedly) в список не входят. Причина — ровно провал сессии 1: «The director
   confirmed…» давало `speaker`, `quote` допускался на новость без цитаты, и
   модель выдумывала высказывание. Регресс закрыт тестами
   `test_speaker_not_from_verb_in_snippet_only` и
   `test_reporting_verbs_are_not_speech`.
