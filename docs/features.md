# Возможности бота «Кино за 5 минут»

Последнее обновление: 1 нояб. 2026.

---

## 1. Сбор материалов

### Источники (фиды)
- **RSS/XML-фиды** — YouTube, новостные сайты, блоgi (28 фидов в sources.yaml).
- **Reddit** — мультиподписка на сабреддиты (`movies`, `boxoffice`, `TrueFilm`, `marvelstudios`, `letterboxd`), парсинг постов и комментариев.
- **Horizon** — локальный дайджест из Markdown-файлов (статьи, заметки).

### Кэширование
- Ответы каждого фida кэшируются в `data/feed_cache/`.
- Повторный запрос только по истечении TTL или при 429.
- Дедупликация по хэшу записи (титул + ссылка).

### Обработка записей
- Извлечение: заголовок, сниппет, ссылка, медиа-URL, дата, видео-ссылка.
- HTML-очистка сниппета.
- Парсинд YouTube-таймкодов для видео-фидов.

## 2. Маршрутизация и классификация

### 11 классов материала (routing.py)
| Класс | Пример |
|-------|--------|
| news | премьера, релиз, закрытие съёмок |
| facts | малоизвестный факт |
| when | даты, платформы |
| quote | цитата |
| behind_scenes | закулисье |
| announcement | анонс |
| riddle | викторина |
| poll | опрос |
| trailer | трейлер |
| video | видео |
| infographic | инфографика |
| collage | галерея |
| comparison | сравнение |
| interview | интервью |
| review | рецензия |
| opinion | мнение |

### Сигналы маршрутизации
- **date** — упоминание даты в title/snippet.
- **number** — число (рейтинги, бюджеты, суммы).
- **speaker** — кавычки в title/snippet ИЛИ глагол речи только в заголовке.
- **video** — видео-ключи в source/title.

### Выбор формата (pick_format)
- Взвешенный рандом с конфигуром весов (`formats.yaml`).
- Фильтр `_SAD_SAFE` — для чувствительных тем безопасные форматы (news/facts/quote).
- Поддержка «mixed» источников с распределением по всем классам.

---

## 3. Выбор темы (deduplication)

### Дедупликация
- Хэш-проверка: титул + ссылка → уникальная запись.
- История выборов хранится в `data/state.json`.

### Франшизный кулдаун
- Не более одного поста про одну франшизу за 36 часов.
- Детектор: кириллические маркеры (`дюн*`, `марвел*`, `нолан*` и т.д.).
- Список франшиз в `config/franchises.yaml` (17 франшиз).

### Релевантность
- Вспомогательные слова (STOP_WORDS + WEAK_WORDS) исключаются из оценки.
- Приоритет: свежие > старые, ключевые слова > шум.

## 4. LLM-генерация текста

### Черновик (draft.py)
- Модель: gemini-3.8-flash (через OpenRouter).
- Промпт: system (~6 КБ) + per-format spec (~1 КБ).
- 16 спецификаций в `prompts/formats/*.txt`.
- Лестница бюджетов: базовый → увеличенный → fallback-модель.
- Парсинг JSON + salvage обрезанных ответов (`jsonparse.balanced_object`).

### Судья (judge.py)
- Модель: deepseek-v4-flash.
- Оценка качества (1–10), sad-темы, обоснование.
- Проверка по правилам judge_system.txt (дата, дубли блоков, key_moment).
- Drop-fields для некорректных полей.
- Те же ретраи и лестница бюджетов, что у черновика.

### Анализатор (analyzer.py)
- Извлечение ключевых слов из текста.
- Оценка качества черновика до LLM.
- Обратная связь по результатам судьи.
- Рекомендации по улучшению.

## 5. Форматы постов

### Короткие «выжимки» (кап 950 символов)
facts, news, when, quote, behind_scenes, announcement, riddle, poll, trailer, video, infographic, collage, comparison

### Длинные (потолок 4096 символов)
interview, review, opinion

### Специфичная доставка
- **poll** — inline-опрос Bot API.
- **trailer / video** — link preview.
- **infographic** — QuickChart PNG-изображение.
- **collage / comparison** — media group (галерея).
- **interview / review / opinion** — статья через Wiki API.

### Подпись (caption.py)
- HTML-экранирование, лечение «хвостов».
- Нормализация хэштегов (лимит 3 шт.).
- Заглушки отбрасываются («не объявлена», «tba»).
- Сверка года с `pub_date`: вырезание неверного года + WARNING.
- Fallback без картинки.

## 7. Расписание и планировщик

### Режимы расписания
- **windows** — старые временные окна (`config/settings.yaml`).
- **slots** — 13 фиксированных слотов по дням недели (SQLite DB).

### Слоты (по умолчанию)
| День | Время |
|------|-------|
| Пн | 11:05, 20:50 |
| Вт | 21:20 |
| Ср | 11:05, 20:50 |
| Чт | 21:20 |
| Пт | 11:05, 20:50, 23:40 |
| Сб | 16:40, 22:00 |
| Вс | 12:00, 19:50 |

### Механика слотов
- Catchup-окно: 30 минут после начала слота.
- Grace-период: 20 минут опоздания (публикует с пометкой).
- Пропущенный слот (> catchup) → `skipped`.
- Отработанная отметка в БД предотвращает повторное срабатывание.

---

## 8. Резервный постинг

### Логика резерва
- Свежий материал нет → прогон отбит → взять из резерва.
- Резерв пуст / просрочено → `skipped` + уведомление админу.
- Только проверенные судьёй посты попадают в резерв.

### Параметры
- `reserve_max_items: 5`
- `reserve_ttl_hours: 48`

## 9. Админка (Telegram-бот)

### Главный экран
```
🎬 Кино за 5 минут
режим: слоты, включено N
резерв: A из T

[🧪 Тестовый пост] [🚀 Финальный пост] [📅 Публикации]
```

### Экран расписания
- Сетка по дням недели, каждый слот — кнопка.
- Добавление/удаление/включение/выключение слотов.
- Превью ближайших 7 дней.
- Журнал последних прогонов (20 записей).

### Команды
| Команда | Действие |
|---------|----------|
| `/start` / `/admin` | Главный экран |
| `/help` | Справка |
| `/schedule` | Экран расписания |
| `/next` | Ближайшие 7 дней |
| `/slot add <день> <HH:MM>` | Добавить слот |
| `/slot del <день> <HH:MM>` | Удалить слот |
| `/slot on <день> <HH:MM>` | Включить слот |
| `/slot off <день> <HH:MM>` | Выключить слот |
| `/slot clear <день>` | Очистить день |

### Постинг по кнопке
- **Тестовый пост**: сбор + превью → в личку админа (канал не трогается).
- **Финальный пост**: полный цикл → в канал.
- Асинхронный прогон (отдельный поток), защита от двойного тапа.

### Доступ
- Только по `ADMIN_CHAT_ID`.
- Проверка на каждом апдейте (chat_id и user_id).

## 10. Мониторинг и логирование

### Статистика
- Сбор статистики форматов (`stats_collector.py`).
- Производительность судьи (токены, время).
- Отчёт качества: avg_overall_quality, recommendations.
- Уведомление при низком качестве контента.

### Логирование
- Настройка через `kino/logging_util.py`.
- Purge старых логов (автоматическая чистка).
- Лог-путь настраивается в конфиге.

## 12. Система уведомлений (systemd)

### Notify socket
- `kino/notify.py` — интеграция с `sd_notify`.
- `ready()` — после загрузки слотов, до первого прогона.
- `status("текст")` — статус в журнале systemctl.
- `stopping()` — мягкая остановка.
- `watchdog()` — периодический пинг (если настроен watchdog).

### Service file
- `deploy/kino.service` — unit для systemd.
- `TimeoutStopSec=300` (бюджет прогона).
- `Type=notify` — notification-based.

## 13. Конфигурация

### Файлы конфига
- `config/settings.yaml` — настройки расписания, лимиты, таймауты.
- `config/sources.yaml` — источники фидов (28 фидов).
- `config/formats.yaml` — веса маршрутизации, drop-fields.
- `config/franchises.yaml` — список франшиз (17 штук).
- `.env` — секреты (BOT_TOKEN, API keys, модели).

### Переменные окружения
- `BOT_TOKEN` — токен Telegram-бота.
- `ADMIN_CHAT_ID` — ID админ-чата.
- `LLM_BASE_URL` — URL шлюза LLM.
- `DRAFT_MODEL` / `JUDGE_MODEL` — модели для черновика/судьи.
- `FALLBACK_MODEL` — модель-фолбэк.
- `STATS_PATH` — путь к директории статистики.
