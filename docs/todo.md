## Правила ведения

- Реализованное убирается из todo немедленно после коммита в main.
- Здесь остаются только ОТКРЫТО (нужно сделать), НАБЛЮДЕНИЕ (не срочно).
- Исторические логи (раунды ревизий, мерджи, мёртвый код) — в архив или ченджлог.
- Статусы: ОТКРЫТО / НАБЛЮДЕНИЕ / РЕШЕНО (решение владельца, ждёт реализации).
