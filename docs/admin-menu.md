# Меню админки Telegram-бота — архивный черновик

> ⚠️ Этот файл **архивный** и больше не является источником правды.
>
> Актуальная спецификация админ-панели: `docs/admin-panel-spec.md`.
> Актуальный статус задач: `docs/todo.md`.

## Почему архив

Исторический черновик `admin-menu.md` описывает старую структуру экранов
(`nav:autoposting:*`, `nav:start`, разделы «О боте», «Бэкап+логи»), которая не
совпадает с текущей реализованной админкой (`nav:sched`, `nav:runs:*`,
`nav:state`, `nav:state:errors`, `nav:runnow`, `add:day:*`).

Чтобы не держать две конфликтующие спецификации, этот документ оставлен только
как историческая заметка. Новые изменения вносятся **только** в
`docs/admin-panel-spec.md`.
