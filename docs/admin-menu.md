# Админка расписания — меню, экраны, команды

Собрано из `kino/admin.py`, `kino/schedule_db.py`, `docs/todo.md`.
Последнее обновление: 1 нояб. 2026.

## Архитектура

`kino/admin.py` — единый модуль, два пути к одному состоянию:

- **кнопки** — основной UI: карточки экранов с инлайн-клавиатурой;
- **команды** — быстрый путь через текстовые команды; каждый ответ — тот же экран с кнопками.

Разделение кода:

- **чистая логика** — `screen_*`, `validate_*`, `handle_command`, `handle_callback`;
  принимает состояние, возвращает `Reply` (текст + клавиатура). Без сети, без Telegram.
- **транспорт** — `poll_once`, `run`; забирает апдейты через `kino.tg_api`, отдаёт чистой логике.

Превью «ближайшие 7 дней» считает теми же функциями, что планировщик (`next_occurrence` из `kino.schedule`).
Отдельной копии логики нет намеренно.

### Доступ

Только по `ADMIN_CHAT_ID`. Проверка на каждом апдейте (и `chat_id`, и `user_id`).
Чужой чат — отказ и запись в лог. Пустой `ADMIN_CHAT_ID` — доступ для всех запрещён.

### Транспорт

`kino/tg_api.py` дублирует транспортную базу `publish.py` (URL, прокси, 429) — сознательно:
публикация возвращает `bool` и не знает про `reply_markup`, админке нужен разбор ответа и `message_id`.
Общий слой появится при третьей поверхности.

## Карта экранов

```
🎬 Кино за 5 минут           ← screen_home()
├── 🧪 Тестовый пост          ← post:test
├── 🚀 Финальный пост         ← post:final
└── 📅 Публикации             ← schedule
    ├── Сетка по дням (7 слотов)
    │   └── Каждый слот — кнопка → slot:{id}
    │       └── Карточка слота → screen_slot()
    │           ├── ⏸ Выключить / ▶️ Включить  ← on:{id} / off:{id}
    │           ├── ✏️ Изменить время          ← edit:{id}
    │           ├── 🗑 Удалить                 ← del:{id}
    │           └── ◀️ Назад                   ← schedule
    ├── ➕ Добавить слот            ← add
    │   └── Подсказка: "Напиши пт 23:40" или "/slot add пт 23:40"
    ├── 👁 Ближайшие 7 дней        ← preview
    │   └── ◀️ Назад                ← schedule
    ├── 📜 Прогоны                  ← runs
    │   └── ◀️ Назад / 🏠 Домой     ← schedule / home
    └── ◀️ Назад                    ← home
```

### Экраны

#### Главный (`screen_home`)

```
🎬 Кино за 5 минут
режим: слоты, включено N
резерв: A из T

Тестовый пост — в личку, канал и state не трогаются.
Финальный — в канал, как по расписанию.

[🧪 Тестовый пост] [🚀 Финальный пост] [📅 Публикации]
```

#### Расписание (`screen_schedule`)

```
📅 Расписание публикаций
слотов: N (включено M)

пн: 11:05, 20:50
вт: 21:20 ⏸
...

[пн 11:05] [пн 20:50] [вт 21:20⏸] ...
[➕ Добавить слот]
[👁 Ближ. 7 дней] [📜 Прогоны]
[◀️ Назад]
```

Если слотов нет:
```
📅 Расписание пусто.
Заполнить сеткой владельца (13 слотов)?
[🌱 Заполнить сетку] [◀️ Назад]
```

#### Карточка слота (`screen_slot`)

```
🕐 Слот понедельник 11:05
Состояние: включён
Последний прогон: 01.11 Mon 11:05 → published

[⏸ Выключить] [✏️ Изменить время]
[🗑 Удалить]
[◀️ Назад]
```

#### Превью (`screen_preview`)

```
👁 Ближайшие 7 дней

01.11 Mon  11:05
01.11 Mon  20:50
...

итого: N
[◀️ Назад]
```

#### Прогоны (`screen_runs`)

```
📜 Последние прогоны

01.11T11:05  published
01.11T11:05  published — опоздание 5 мин
...

Резерв: доступно A из T
[◀️ Назад] [🏠 Домой]
```

## Команды

| Команда | Действие |
|---------|----------|
| `/start` или `/admin` | Главный экран |
| `/help` | Справка |
| `/schedule` | Экран расписания |
| `/next` | Ближайшие 7 дней |
| `/slot add <день> <HH:MM>` | Добавить слот |
| `/slot del <день> <HH:MM>` | Удалить слот |
| `/slot on <день> <HH:MM>` | Включить слот |
| `/slot off <день> <HH:MM>` | Выключить слот |
| `/slot clear <день>` | Очистить все слоты дня |

День: `пн`, `вт`, `ср`, `чт`, `пт`, `сб`, `вс`.

---

## Валидация

- Время: `HH:MM`, диапазон 00:00–23:59. Мусор → понятная ошибка.
- День недели: одно слово из списка. Непонятное → подсказка.
- Дубль: если слот `пн 11:05` уже есть → отказ.
- Лимит дня: больше 10 слотов → предупреждение (не запрет).

---

## Постинг по кнопке

Обе кнопки (`post:test` / `post:final`) запускают прогон в отдельном потоке.
Кнопка сразу отвечает «запущено», бот не замирает. Второй тап во время прогона — отказ.

- **Тестовый пост**: `build_only()` → `preview_text()` → отправка в личку админа. Если `deliver()` упал — предупреждение.
- **Финальный пост**: `publish_now()` → результат через `describe_result()`.

   `reserve`/`skipped`. Значение осталось в схеме и `OUTCOMES` для ручных записей.
   Причина уже есть в `reason`.

5. **Ручная правка времени из карточки не принимается текстом** (набл. 86).
   Нужен слой «жду ввода» на чат. Сейчас — `/slot add` + `/slot del`.

6. **`kino-admin.service` без watchdog** (набл. 89). У админки нет цикла,
   который стоит сторожить. Зависание видно по отсутствию ответа.
   `Type=notify` добавляется тем же `notify.ready()` в `admin.run`.
