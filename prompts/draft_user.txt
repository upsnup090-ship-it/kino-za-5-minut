Верни JSON со всеми базовыми полями (описаны выше) и формат-специфичными
полями из спецификации:
poll_options, video_url, infographic, image_candidates,
announcement, review, comparison, riddle,
fact_source, news, quote, trailer, video, collage,
production, interview, opinion.

Заполняй только поля формата {format}; остальные — [] для массивов, null для
объектов, "" для строк.

Дата материала — единственный источник года. Если дата «(неизвестна)»,
год в fact_source и в тексте не указывай вовсе: «Материал Variety», без года.
Не подставляй год по памяти и не угадывай его по названию фильма.
