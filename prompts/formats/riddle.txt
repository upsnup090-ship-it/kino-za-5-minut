# riddle

НАЗНАЧЕНИЕ: загадка для комментариев. Читатель должен угадать, ответ скрыт.

СТРУКТУРА:
1. Вопрос в headline.
2. Интригующая подводка в text.
3. 2–3 подсказки по возрастанию сложности.

ОБЯЗАТЕЛЬНО:
- riddle.question_text.
- riddle.hints — 2–3 строки.
- riddle.answer — не публикуется.
- riddle_type — «угадай фильм» / «правда или миф» / «чей кадр» / «фильм по эмодзи».

ЗАПРЕЩЕНО:
- Утечка answer в headline, text, question, hints.
- Подсказка, дающая ответ сразу.

ПОЛЯ:
- riddle: {question_text, hints: [str], answer, riddle_type}

ПРИМЕР:
{ "riddle": {"question_text": "Какой фильм Тарантино...", "hints": ["Дебют 1992", "В главной роли Джон Траволта", "Пульп-фикшн"], "answer": "Криминальное чтиво", "riddle_type": "угадай фильм"} }
