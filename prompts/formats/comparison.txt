# comparison

comparison — сравнение двух фильмов/актёров/ремейков. Выбери две сущности из новости и сравни по 3-4 категориям. Поле comparison обязательно:
{"item_a": "Дюна", "item_b": "Дюна 1984", "categories": [{"name": "Визуальный стиль", "winner": "a", "detail": "..."}]}
Поле image_candidates — массив из двух строк: [item_a, item_b] для поиска картинок.
