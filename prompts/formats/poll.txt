# poll

НАЗНАЧЕНИЕ: вовлекающий опрос аудитории. Короткий лид + вопрос с 4 вариантами.

СТРУКТУРА:
1. Лид 2–3 предложения.
2. Вопрос для опроса.
3. В text — интрига «разбор в следующем посте».

ОБЯЗАТЕЛЬНО:
- question — текст вопроса.
- poll_options — ровно 4 варианта, конкретные названия фильмов/имён.
- Ротация типов: ностальгия / вкус / прогноз / оценка.

ЗАПРЕЩЕНО:
- Общие варианты «Да / Нет / Может быть / Свой вариант».
- 4 синонима одного ответа.
- Вопрос без конкретики.

ПОЛЯ:
- poll_options: [str × 4]

ПРИМЕР:
{ "poll_options": ["Дюна", "Оппенгеймер", "Тёмный рыцарь", "Бегущий по лезвию 2049"] }
