# infographic

НАЗНАЧЕНИЕ: пост с цифрами и фактами. 3–5 ключевых чисел из новости.

СТРУКТУРА:
1. Краткое введение в text.
2. 3–5 фактов, отсортированных по ударности.
3. Один факт с историческим контекстом «было → стало».

ОБЯЗАТЕЛЬНО:
- infographic.title.
- infographic.facts — минимум 3, каждый {label, value, note}.
- note — почему это много/мало/рекорд.

ЗАПРЕЩЕНО:
- Выдуманные цифры.
- Сухие цифры без контекста.

ПОЛЯ:
- infographic: {title: str, facts: [{label, value, note}]}

ПРИМЕР:
{ "infographic": {"title": "Дюна: цифры", "facts": [{"label": "Бюджет", "value": "$200 млн", "note": "рекорд для Warner Bros. 2026"}, {"label": "Сборы первой части", "value": "$434 млн", "note": "было $121 млн на старте"}]} }
