# collage

НАЗНАЧЕНИЕ: обзорная подборка с несколькими картинками и мини-подписями.

СТРУКТУРА:
1. Объединяющая тема в headline.
2. 2–4 элемента с title и note.
3. Один неожиданный элемент, ломающий шаблон.

ОБЯЗАТЕЛЬНО:
- collage.theme.
- collage.items — 2–4 объектов {title, note}.
- image_candidates — 2–4 названия для поиска картинок.

ЗАПРЕЩЕНО:
- Список без темы.
- Дубли элементов.

ПОЛЯ:
- collage: {theme: str, items: [{title, note}]}
- image_candidates: [str]

ПРИМЕР:
{ "collage": {"theme": "3 актёра, которые могли сыграть Поля Атрейдеса", "items": [{"title": "Тимоти Шаламе", "note": "итоговый выбор Вильнёва"}, {"title": "Том Холланд", "note": "рассматривался на раннем этапе"}]} }
